The ASV table

The ASV table is the occurrence or abundance table that contains counts corresponding to the number of times each ASV is observed in each sample.

The ASV table has samples in rows and variables (ASVs) in columns.

This is the asv_count.df table from our raw data. We can get the same information from a phyloseq object using the otu_table() function.

Rarefaction Curve

Rarefying is a method of normalization. This step allows for visualization of ASV richness across sampling depths. The key for interpreting this curve, is to identify where ASV richness plateaus. This means that more diversity is not being captured even as sequencing depth increases. The point of plateau can serve as the cutoff normalization where the maximum amount of ASV diversity is kept while prioritizing even sequence depth across samples for downstream processing. Rarefying is ideal for beta diversity analyses.

rarecurve(red.asv, step = 1000, sample = min(rowSums(red.asv)),
          col = "blue", label = FALSE, main = "Rarefaction Curves for All Samples")

Negative and Positive Controls

Negative Controls

It is important to include negative controls throughout the extraction and amplification process. These can include blank samples that go through the extraction process, and no-template controls that go through the amplification process. These negatives can then be used to ensure these steps are not amplifying unwanted DNA from the laboratory environment

View(asv.table2) # Sample names as columns
  1. Scroll to BLANK or NEG samples
  2. Order from high to low to see counts for most abundant ASVs
  3. Interpret:
  • Reads should be below 1000 per ASV
  • Sample should contain less than 100 different ASVs
  • If higher than these benchmarks, this could be problematic for interpreting ASVs in actual samples and further steps should be taken to account for these ASVs

Checking sparsity

Microbiome datasets are usually sparse and have an uneven library size.

#check the number of zeros in the OTU table
sum(asv_count.df == 0)

#check the percentage of zeros in the OTU table
sum(asv_count.df == 0) / (nb_var * nb_samples) * 100
Discussion point

  • What is the meaning of a zero value in an OTU table?

  • Can we consider it to be a true zero?

  • Do you think it is important to filter the data and why?

Answers

  • A zero value in the OTU table means that we could not sequence any read for a specific OTU/ASV in a given sample. This means that there is not such OTU/ASV in the given sample or that the sequencing depth was not enough to find it.

  • So, we usually don’t know if it is a true zero or not.

  • First, some statistical approaches cannot handle highly sparse data set (for example Principal Component Analysis). Then, there is often problem when we have to compare rare OTU/ASV. For example, if for one sample you cannot find any count for a specific OTU but for another sample you can find 1 count for this OTU, can you say that there is more of this OTU in the second sample than in the first one? Therefore, in the context of microbiota data analysis, zeros values can be difficult to analyse and interpret and data should often be filtered.

Q: how do you interpret these results; Do you think it is an issue to have variation in the library size?

[Of course if you want to compare samples to each other, it will be an issue to have different library sizes. For example, if you have a sample 1 with 1000 reads (500 reads for OTU1, 300 reads for OTU 2 and 200 reads for OTU 3) and a sample 2 with only 100 reads (50 reads for OTU1, 30 reads for OTU 2 and 20 reads for OTU 3). If you are comparing the two samples without correcting for the library size, you will say that sample 2 as 10 times less OTU 1, 2 and 3 than the sample 1, while it is just due to the difference in library size. Indeed, if you calculate the percentage, you will have 50% of OTU 1, 30% of OTU 2 and 20% of OTU 3 for both samples. So, > > it is important to normalize your data per sample.]

The taxonomy table

The taxonomy table (taxa.df) represents the assignment for the different OTU at domain, phylum, class, order, family, genus and species levels. Usually, microbial ecologists use phylum level (or class level for Proteobacteria) to describe the global bacterial communities. Then, they usually use OTU, ASV (Amplicon Sequence Variant) or genus level to check which bacteria are differentially occuring in the different treatments.
