Calculating diversity indices

Two common diversity measures reported in microbiome studies are alpha and beta diversity:

  • Alpha diversity describes the species richness, evenness, or presence alone within a sample.

  • Beta-diversity measures compare the similarity of two or more communities.

Alpha diversity

Each index take into account different factors which gives them unique advantages for assessing species diversity.

  • Shannon: based on richness & evenness - prioritizes spread of species within a sample

  • Chao: based on richness & presence - prioritizes detection of rare species within a sample

Here, we are going to generate alpha-diversity plots following this tutorial.

asv.rich <- estimateR(raref.asv) # calculate species richness - uses integers or counts
asv.even <- diversity(asv.table) / log(specnumber(asv.table)) # calculate species evenness - uses proportion

# Calculate diversity index that combines species richness and evenness
asv.div <- diversity(asv.table, index="shannon") # replace with chao or simpson

hist(asv.div, main = "Histogram of Shannon Diversity", xlab = "Shannon Diversity")

# Test normality of distribution
shapiro.test(asv.div) # <0.01 is non-normal

# Plot with statistical test by treatment (e.g. by Steep_Time)
common <- intersect(names(asv.div), rownames(asv.table))

df.shannon <- data.frame(
  Shannon = asv.div[common],
  Steep_Time = raref.metadat[common, "Steep_Time"]
)


df.shannon$Steep_Time <- factor(df.shannon$Steep_Time, 
                              levels = c("0", "1", "2", "5", "14", "21", "28"))

# Test statistical significance between diversity indices of each treatment level
kruskal.test(Shannon ~ Steep_Time, data = df.shannon) # Kruskal-Wallis is a statistical test for non-normal distributions

pairwise.wilcox.test(df.shannon$Shannon, df.shannon$Steep_Time,
                     p.adjust.method = "fdr") # p-adjusment helps limit false positives from multiple comparisons

quartz() # opens a new figure window on Mac
ggplot(df.shannon, aes(x = Steep_Time, y = Shannon, fill = Steep_Time)) +
  geom_boxplot(outlier.shape = NA, alpha = 0.8) +
  geom_jitter(width = 0.2, size = 1.5) +
  labs(title = "Shannon Diversity over Time spent in Compost Tea",
       x = "Steep Time",
       y = "Shannon Diversity") +
  theme_minimal() +
  scale_fill_manual(values = c("28" = "#006475", "21" = "#00a1b7", "14" = "#56d0d8", "5" = "#596028", "2" = "#898929", "1"="#606571", "0" = "black")) +
  stat_compare_means(method = "kruskal.test", label.y = max(df.shannon$Shannon) + 0.7) +
  stat_compare_means(method = "wilcox.test",
                     comparisons = list(c("0", "1", "2", "5", "14", "21", "28")),
                    label = "p.signif")

Beta diversity

Principal Components Analysis (PCoA)

A Principals Component Analysis, or PCoA, is an ordination technique that lets us visualize high-dimensional data. In a nutshell, it reduces high-dimensional data into a smaller number of dimensions so we can plot it in 2D.

asv.bray <- vegdist(asv.table)

asv.bray.table <- as.data.frame(asv.bray)
asv.pcoa <- cmdscale(asv.bray, k=(nrow(asv.perc)-1), eig=TRUE)

# Store coordinates for first two axes in new variable #
asv.p <- asv.pcoa$points[,1:2]

# Calculate % variance explained by each axis #
asv.eig<-asv.pcoa$eig
perc.exp<-asv.eig/(sum(asv.eig))*100
pe1<-perc.exp[1]
pe2<-perc.exp[2]

# Build PCoA dataframe
pcoa_df <- data.frame(
  Sample = rownames(asv.p),
  PCoA1 = asv.p[,1],
  PCoA2 = asv.p[,2],
  Group = raref.metadat$Steep_Time)

ggplot(pcoa_df, aes(PCoA1, PCoA2, color = Group, fill = Group)) +
 geom_point(shape = 21, size = 3, stroke = 1) +
  labs(x = paste0("PCoA1 (", round(pe1, 2), "% variance explained)"),
    y = paste0("PCoA2 (", round(pe2, 2), "% variance explained)"),
    title = "PCoA of ASVs (Bray-Curtis)") +
  scale_color_manual(values = c( "1" = "gray", "2" = "red", "5" = "orange", "14" = "gold", "21" = "chartreuse4","28" = "blue1"), breaks = c("1", "2", "5", "14", "21", "28")) +
  scale_fill_manual(values = c( "1" = "gray", "2" = "red", "5" = "orange", "14" = "gold", "21" = "chartreuse4","28" = "blue1"), breaks = c("1", "2", "5", "14", "21", "28")) + 
  theme_minimal()

You can play with removing points from the plot to see how treatment groups may be separating from each other. However, this is not a true subset.

pcoa_df_sub <- subset(pcoa_df, Group %in% c("1", "28"))

ggplot(pcoa_df_sub, aes(PCoA1, PCoA2, color = Group, fill = Group)) +

Density Plots

# Pull out axes of variance from ordination object into dataframe 
dens_df1 <- data.frame(SampleID = rownames(asv.p),PCoA1 = asv.p[,1],PCoA2 = asv.p[,2])

# Join with treatment metadata 
dens_df2 <- raref.metadat%>%rownames_to_column("SampleID")  
dens_df3 <- dens_df1%>%inner_join(dens_df2,by="SampleID") 
dens_df4 <- dens_df3 %>% filter(Steep_Time %in% c("1", "28")) 

# Make density plots
