Introduction

Being able to work competently with R is incredibly useful and versatile. In addition to performing any statistical tests you like, R allows you to make professional-looking graphs and figures. If there is something you want to do with R, odds are you can do it. You just have to figure out how…

When trying to figure out how to do something, I recommend the following approaches:

  • Google search what you are trying to do, followed by “in R”. So for instance “Make box plot in R”. There is an extensive user community.

  • If you see a command in a script you are following, and don’t know what it means, use the ‘?’ function. For example, running ?ggplot will tell you all about the ggplot function, including its available parameters.

  • Use existing tutorials and resources to give you a pipeline for processing data. Go through with the sample data first to make sure it all works. Then substitute your own data.

Resources I would recommend include:

  • R for Data Science, Elegant Graphics for Data Analysis, and Advanced R by Hadley Wickham.

  • Cheatsheets by Posit (formerly RStudio).

  • Friends Don’t Let Friends Make Bad Graphs by Chenxin Li.

  • Online R Learning by Chenxlin Li.

  • The Carpentries workshops e.g., Data Analysis and Visualization in R for Ecologists.

  • Numerical Ecology in R by Daniel Borcard, Francois Gillet, and Pierre Legendre.

Getting started with RStudio

R is a programming language. In this workshop, we’re going to be working in RStudio, an Integrated Development Environment that lets us easily write and edit code.

RStudio interface

The RStudio user interface has 4 primary panes:

  • Source pane: allows you to view and edit various code-related files.

  • Console pane: provides an area to interactively execute code.

  • Environment pane: displays currently saved R objects.

  • Output pane: contains the Files, Plots, Packages, and Help tabs.

R basics

Running code

There are a few ways to run code:

  • Click the line and select CTRL + ENTER

  • Highlight the line and select CTRL + ENTER

  • Click the line and click ‘Run’ in the top menu bar

  • In a R or Quarto markdown document, you can click the green ‘play’ button to run all of the code in the current chunk. Code chunks run from ```{r} to the next ``` . Each chunk should have a unique name.

You can also copy and paste (or type) code directly into the console pane after the ‘>’ prompt. Select ENTER to run the code.

Using functions

To make something happen in R, you use a function. For example, the sqrt function calculates the square root of a given number. To use a function, you’ll need to write it’s name with parentheses.

The inputs you give a function go inside those parentheses - these are called arguments.

For example, we can use the sqrt() function to calculate the square root of 256, by providing that number as our argument.

sqrt(256)
[1] 16

In it’s simplest form, R code works like this:

object <- function(argument)

where:

  • an object holds a value e.g., the output of a function, a dataframe, a list.

  • the left arrow operator <- assigns a value.

  • A function does something e.g., performs a calculation, plots observations.

  • An argument is an input or parameter e.g., the data or a setting you want to use.

Installing & loading packages

Installing and loading packages

R comes prepackaged with some default functions. You can install packages to get access to new collections of functions.

We can install new packages using the install.packages() function.

We only need to download and install a package once.

#Many popular R packages are hosted on CRAN (Comprehensive R Archive Network) and can be installed with the install.packages() function
install.packages("tidyverse")

However, every time we open RStudio, we need to load the packages we want to use in that session using the library() function.

library(tidyverse)

Creating objects

If you want to use the output of R functions later, you’ll need to save them. In R, you can save outputs and results by creating an object.

To create an object, type a name for the object and use the <- arrow to store a value in the object. You can call this literally anything you like, so long as it’s one string of characters.

my_favourite_number <- 256
my_favourite_number #this object holds the value '256'

sqrt(my_favourite_number)

my_new_favourite_number <- sqrt(my_favourite_number) #what value is stored in this new object?

Introducing the Palmer penguins

The Palmer penguins dataset contains size measurements for three penguin species observed on three islands in the Palmer Archipelago, Antarctica.

This data was collected from 2007 to 2009 by the US Long Term Ecological Research Network.

Creating an R script

Before we start working on our code, we want to create an .R document we can save it in!

File > New File > R Script

To make sure your code is reproducible, it’s good practice to load all the packages you need at the start of your document, using the library() function.

install.packages("tidyverse")
library(tidyverse)

Tidyverse is a collection of packages used for data manipulation, filtering and visualisation. Today, we’ll use functions from tidyverse to import data and create some plots.

It’s in the name - the first step to any data analysis is to make sure your data is tidy!

Creating plots with ggplot()

ggplot() is a function that creates plots.

Like a piece of art, we start with a base canvas where we set up our framework. We then use a + symbol to add layers on top.

ggplot() components

Every ggplot has three components:

  • data - your filtered data, ready for visualisation.
  • aesthetic mappings - this defines which variables we plot.
  • geom layer(s) - this defines how we visualise the observations.

Geom layers

Example 1: creating the canvas base

ggplot(data = penguin_nafree.data, aes(x = bill_length_mm, y = bill_depth_mm))

Example 1: adding a geom layer

ggplot(data = penguin_nafree.data, aes(x = bill_length_mm, y = bill_depth_mm)) +
  geom_point(size = 2)

Example 1: point colour and shape

ggplot(data = penguin_nafree.data, aes(x = bill_length_mm, y = bill_depth_mm)) +
  geom_point(aes(color = species, shape = species),size = 2)

ggplot(data = penguin_nafree.data, aes(x = bill_length_mm, y = bill_depth_mm)) +

Example 4: creating a bar plot with error bars

#calculating sd
penguin_summary.data <- penguin_nafree.data %>%
  group_by(species) %>%
  summarise(
    sd = sd(body_mass_g),
    body_mass_g = mean(body_mass_g)
  )

#bar plot with error bars
ggplot(data = penguin_summary.data, aes(x = species, y=body_mass_g)) +
  geom_col(aes(fill=species),position="dodge") +
  geom_errorbar(aes(ymin=body_mass_g-sd, ymax=body_mass_g+sd), width=.2,
                position=position_dodge(.9)) + 
  scale_fill_manual(values = c("darkorange","darkorchid","cyan4"), name = "Penguin species") +
  labs(y="Weight (g)", x="Penguin species") +
  theme_bw()

Dealing with errors

What to do when you get an error

  • Read the error message

  • Google the error message

  • Try the suggested solutions

  • Read about the function

  • Ask for help

Check the easy stuff:

✅ Did you forget to run any code?

✅ Check for spelling mistakes (including capital letters)

✅ Check your parentheses, quotation marks, and commas
